# Oracle-disease

Oracle-disease is a research repository for reproducible comparison of motion-trajectory and multivariate time-series classification networks.

The currently started reproduction is **Singh & Koundal (2024) TCN**. Each future paper reproduction will live in its own top-level directory so that implementations remain isolated and comparable.

Datasets, participant data, checkpoints, training outputs, and caches are not committed to Git.

## Current reproductions

- [`TCN_Singh2024/`](TCN_Singh2024/): Temporal Convolutional Network for raw 3D air-writing trajectories.

No numerical reproduction results are claimed in this repository until real dataset experiments have been completed.
